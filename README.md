# 🎨 Color Palette Generator

A sleek and responsive web app that lets you generate beautiful color palettes from a base color. Built using **React** and styled for a modern, matte black UI.

## 🚀 Features

- 🎨 Select a base color using a color picker
- 🌈 Automatically generates complementary color palettes
- 💾 Copy palette values for use in your design projects
- 📱 Responsive design for mobile and desktop
- 🌓 Dark matte theme for an elegant experience
